# i18n — Підтримка Української та Англійської мов

**Дата:** 2026-05-20  
**Статус:** Затверджено  

---

## Мета

Додати перемикання мов (UK / EN) у додаток Деберц. Поточний стан: весь UI захардкоджено українською. Ціль: повний переклад інтерфейсу, зберігаючи вибір мови між сесіями.

---

## Архітектура

### Бібліотека

`react-i18next` + `i18next` — промисловий стандарт, нульова async-складність при bundled-підході.

### Нові файли

```
src/i18n/
  index.ts          — синхронна ініціалізація i18next, TypeScript augmentation
  locales/uk.ts     — українські рядки (джерело правди для ключів)
  locales/en.ts     — англійські рядки (TypeScript гарантує ті самі ключі)
```

### TypeScript type safety

У `src/i18n/index.ts`:

```ts
declare module 'i18next' {
  interface CustomTypeOptions {
    resources: { translation: typeof import('./locales/uk').default }
  }
}
```

- `t('nonExistent')` → compile error
- `en.ts` мусить мати ті самі ключі що й `uk.ts` (перевіряється через `satisfies` або explicit type)

### Ініціалізація

```ts
i18next.use(initReactI18next).init({
  lng: localStorage.getItem('lang') ?? 'uk',
  fallbackLng: 'uk',
  resources: { uk: { translation: uk }, en: { translation: en } },
  interpolation: { escapeValue: false },
})
```

Синхронна, без `Suspense`, без HTTP-запитів. PWA/офлайн-сумісна.

## Перемикач мови

**Розміщення:** `GameHeader.tsx` — поруч з кнопкою звуку.

**Вигляд:** текстова кнопка `УК` / `EN` в casino dark стилі, аналогічно кнопці звуку.

**Пропси:**
- `App.tsx` зберігає `lang: 'uk' | 'en'` у стані
- Передає `lang` + `onLangChange` у `GameHeader` (як `soundEnabled` / `onSoundToggle`)

**Персистентність:** `localStorage` ключ `lang` — оновлюється при кожному перемиканні. Зчитується при ініціалізації i18next.

## Структура ключів перекладу

Плоска структура з namespace-префіксами. Інтерполяція через `{{variable}}`.

```ts
// Загальне
"app.title"            // "Деберц" / "Deberc"
"app.targetScore"      // "До {{n}} очок" / "To {{n}} points"
"app.round"            // "Раунд {{n}}" / "Round {{n}}"

// SetupScreen
"setup.title"          // "Нова гра" / "New Game"
"setup.playerName"     // "Гравець {{n}}" / "Player {{n}}"
"setup.startGame"      // "Почати гру" / "Start Game"
"setup.targetScore"    // "Гра до" / "Play to"
"setup.rules"          // заголовок правил / Rules header

// GameHeader
"header.newGame"       // "Нова гра" / "New Game"
"header.undo"          // "↩ Відмінити" / "↩ Undo"
"header.confirmNewGame" // "Почати нову гру?" / "Start a new game?"
"header.confirmYes"    // "Так" / "Yes"
"header.confirmNo"     // "Скасувати" / "Cancel"

// RoundForm
"round.submit"         // "Підтвердити раунд" / "Submit Round"
"round.dealer"         // "Роздає: {{name}}" / "Dealer: {{name}}"
"round.error.oneVis"   // помилка ВіС / ВіС error
"round.error.oneB"     // помилка Б / Б error

// ScoreBoard
"score.leader"         // "Лідер" / "Leader"
"score.closeToFinish"  // "Близько до фінішу" / "Close to finish"

// WinnerScreen
"winner.title"         // "{{name}} переміг!" / "{{name}} wins!"
"winner.newGame"       // "Нова гра" / "New Game"

// RecoverScreen
"recover.title"        // "Відновити гру?" / "Resume Game?"
"recover.subtitle"     // "Знайдено незавершену гру" / "Unfinished game found"
"recover.resume"       // "Продовжити" / "Resume"
"recover.newGame"      // "Нова гра" / "New Game"

// RoundHistory
"history.title"        // "Історія раундів" / "Round History"
"history.round"        // "Р{{n}}" / "R{{n}}"
"history.undo"         // "Відмінити останній раунд?" / "Undo last round?"

// PlayerStatistics / GameHistory
"stats.wins"           // "Перемог" / "Wins"
"stats.rounds"         // "Раундів" / "Rounds"
"stats.total"          // "Всього" / "Total"
```

## Що НЕ перекладається

- `'Б'`, `'ХВ'`, `'ВіС'` — власні назви ігрових одиниць, залишаються українськими в обох мовах
- Імена гравців — юзерські дані, не торкаємось
